# Ghost-Game
Game of ghosts doors.
The in-game text is written in Russian, but if that bothers you, you can change it yourself; the code is clean and clutter-free. Everything is included only as needed, and I’ve tried to optimize everything!

# How to use
Just compile the code and answer the questions! At the beginning, you’ll be asked if you want to play—say “yes” to enter the game and “no” to exit! Enjoy! (The text is in Russian! Please translate it yourself.)
